# دليل الاستخدام - المرحلة 1

## الدخول الأول
- اسم المستخدم: `admin` — كلمة المرور: `admin123`
- **غيّر كلمة المرور فوراً** من: الإعدادات ← تغيير كلمة المرور الخاصة بي.

## المدير
- الأصناف: زر (+) للإضافة، والضغط على الصنف للتعديل أو الحذف.
- الإعدادات: تعديل اسم المتجر/الفرع/الإدارة، إضافة بائع، تغيير كلمة مرور البائع، تعطيل حسابه.
- الفواتير: الضغط على الفاتورة ثم "إلغاء الفاتورة" مع كتابة السبب (يرجع المخزون تلقائياً).

## البائع
- الكاشير: ابحث بالاسم أو امسح الباركود (قارئ الباركود الخارجي يعمل كلوحة مفاتيح).
- لا يرى أسعار الشراء ولا الأرباح ولا يعدّل الأسعار.

## قريباً (المراحل 2 و 3)
المشتريات والموردون، الجرد، المرتجعات، الخزينة والورديات، التقارير (Excel/PDF)، النسخ الاحتياطي والاستعادة، البيع الصوتي، الطباعة.

## بناء ملف APK
1. ارفع مجلد المشروع كاملاً على مستودع GitHub.
2. ادخل تبويب Actions ← Build APK ← انتظر انتهاء البناء.
3. نزّل `rif-market-apk` من قسم Artifacts وثبّت `app-release.apk` على الهاتف.
